# Evaluation (PROMPT 7)

Reproducible RAG quality measurement for the VateCon support agent.

## Dataset

Synthetic but realistic knowledge base and labeled questions for a
fictional SaaS product (**NimbusDesk**). Generated by script with a
fixed seed — never hand-edited the JSONL without bumping `VERSION`.

```bash
python evaluation/scripts/generate_dataset.py
```

Artifacts land in `evaluation/dataset/`:

| Path | Contents |
|------|----------|
| `VERSION` | Dataset revision id |
| `knowledge/*.md` | Indexed source documents |
| `questions.jsonl` | Labeled evaluation items |
| `manifest.json` | Counts, seed, checksums |

See `dataset/schema.py` for the JSONL field contract.

## Harness

Offline extractive stand-in (no live OpenAI). Measures retrieval,
generation proxies, escalation PRF, confidence ECE, latency, and
estimated cost / 1 000 requests.

```bash
pip install -r backend/requirements.txt
pip install -e "backend/[dev]"
pip install -r evaluation/requirements.txt   # charts
make eval
```

`make eval` runs `evaluation/tests` then `run_eval.py`. Reports land
in `evaluation/reports/` (`report.json`, `report.md`, charts). The
process exits non-zero if `recall@5` is below `RECALL_AT_5_THRESHOLD`
(default `0.35`).

CI: `.github/workflows/eval.yml` runs the same gate on every PR/push
to `main`, and on a weekly schedule (Monday 06:00 UTC) so reports are
published as the `rag-eval-reports` artifact.
